Instrucciones públicas para todos los agentes que trabajen en este repositorio.
Leer también `CLAUDE.md` y `ESTADO.md` antes de actuar y conservar trabajo ajeno.

## Trabajamos 100 % en la nube — 5-nov-2026

- Todo el desarrollo y la ejecución se hacen en la nube: Devin, GitHub o un
  servidor autorizado. Nunca en el Mac ni dependiendo de que esté encendido.
- Las herramientas, guías y conexiones se preparan donde corre el trabajo.
- Esta regla prevalece sobre instrucciones antiguas de trabajar desde el Mac.
  Sus dependencias quedan pendientes de revisión y autorización: no mover,
  instalar, sustituir ni activar nada por esta norma.
- GitHub es la fuente compartida. Actualizar la base sin perder trabajo, leer
  reglas y estado, respetar el turno y usar rama/worktree propios.
- No amplía permisos de servidor ni producción: requieren el OK específico de
  Víctor, identidad autorizada y turno. No sustituir una vía del Mac por SSH u
  otro agente para eludir esos límites.
- Mantener secretos y datos personales fuera del repositorio, notas y chats;
  usar únicamente los almacenes autorizados.
- Cerrar con estado fechado, commit en español y PR. No fusionar, desplegar ni
  publicar sin autorización expresa.
